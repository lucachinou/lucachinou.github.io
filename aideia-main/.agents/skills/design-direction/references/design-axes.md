# Design axes reference

These axes make visual decisions explicit. They are not presets.

## Density
- sparse — few simultaneous controls, generous whitespace
- comfortable — ordinary product density
- compact — more information per viewport with controlled spacing
- information-dense — tables, monitoring and power-user UI

## Geometry
- sharp — near-square corners and strict silhouettes
- restrained-radius — modest rounding used consistently
- soft — noticeably rounded system
- product-specific — geometry derived from a domain motif

## Surface
- flat — hierarchy mostly through spacing/type/color
- bordered — separation through lines and restrained surfaces
- layered — nested depth with clear hierarchy
- elevated — shadows/elevation communicate structure
- textured — material/noise/image texture is intentional identity

## Typography
- neutral — interface-first and quiet
- editorial — type rhythm carries much of the character
- technical — data, mono or compact metrics matter
- playful — expressive type supports the product tone
- display-led — display typography is a primary identity signal

## Contrast
- quiet
- balanced
- high
- dramatic

## Color behavior
- monochrome-led
- sparse accent
- semantic-rich
- expressive
- product-specific

## Composition
- grid-regular
- asymmetric
- editorial
- tool-like
- immersive
- product-specific

## Navigation
- top-led
- side-led
- contextual
- command-led
- in-world/product-native

## Motion
- nearly static
- snappy
- mechanical
- soft
- expressive

## Imagery
- none
- product screenshots/content
- photography
- illustration
- 3D
- game-native assets

## Data treatment
- prose-led
- list-led
- table-led
- chart-led
- spatial
- mixed

## Signature motif

Optional. It should be tied to the product and reused with restraint.

Good:
A recurring treatment derived from the game's material language, or a tool-specific interaction pattern.

Bad:
"Add particles/glow because the screen needs personality."

## Variation principle

Create identity by combining several product-appropriate stances. Never rely on one dramatic effect as the only differentiator.
