# UI copy

Read:
- ../../../rules/CONTENT.md
- ../../../rules/ANTI_AI_SLOP.md

## Workflow

1. Identify the user's task at each surface.
2. Preserve required product/legal/domain terminology.
3. Remove text that only repeats obvious UI.
4. Replace vague CTA labels with concrete actions when possible.
5. Keep helper text only when it prevents confusion or explains a constraint.
6. Make errors state what failed and what can be done next.
7. Never invent facts, metrics, urgency, trust claims or capabilities.
8. Match the product's established tone.

## Test

For every visible string ask:
- Would the user lose useful information if this disappeared?
- Is the same meaning already visible nearby?
- Is this factual and supported?
- Is this written for the user rather than to make the design look fuller?

Prefer silence over filler.
